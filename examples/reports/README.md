# Synthetic example reports

These files are generated by `node scripts/demo.mjs`. The demo runs a temporary vulnerable fixture, applies the supplied corrected fixture and retests unchanged acceptance assertions. It exports:

- `vulnerable.json` / `vulnerable.md`: 14 intentional assertion failures plus a source-pattern hypothesis.
- `corrected.json` / `corrected.md`: 14 passing assertions for this limited fixture.
- `comparison.json`: fresh scenario resolution; absent static warning remains unverified.
- `demo-validation.json`: actual execution counts and environment.

Paths identifying the temporary local fixture are replaced with `/synthetic-fixture` in exported examples. These exported examples are for reading, not importing into a live engine's private state store. They contain synthetic data only. All 101 applicability decisions are visible, but fixture-specific exclusions do not apply to a real product. Real provider delivery remains unverified.
